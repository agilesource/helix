## 三、核心模块设计

### 3.1 Orchestrator 完善

**当前问题:**
- 意图识别基于简单关键词匹配
- 无上下文感知

**v1.0.0 改进:**

```python
class HelixOrchestrator:
    """核心编排器"""

    def __init__(self, config: HelixConfig):
        self.config = config
        self.context = HelixContext()
        self._skills: Dict[str, Skill] = {}
        self._intent_classifier = IntentClassifier()  # 新增

    async def run(self, user_input: str) -> SkillResult:
        # 1. 增强意图识别
        intent = await self._intent_classifier.classify(user_input, self.context)

        # 2. 技能路由
        skill = self._route_skill(intent)

        # 3. 执行
        result = await skill.execute(intent, self.context)

        # 4. 更新上下文
        self.context.add_interaction(intent, result)

        return result
```

### 3.3 Skills 基类完善

**当前问题:**
- validate 方法默认返回 True
- 无执行超时处理

**v1.0.0 改进:**

```python
class Skill(ABC):
    """技能基类 v1.0.0"""

    async def execute(self, intent: Intent, context: HelixContext) -> SkillResult:
        """执行入口 (模板方法)"""
        start_time = asyncio.get_event_loop().time()

        try:
            # 1. 验证
            is_valid, error = await self.validate(intent, context)
            if not is_valid:
                return SkillResult(
                    success=False,
                    message=f"Validation failed: {error}",
                    skill_name=self.name
                )

            # 2. 初始化
            self.initialize()

            # 3. 执行 (带超时)
            result = await asyncio.wait_for(
                self._do_execute(intent, context),
                timeout=self.config.timeout_seconds
            )

            # 4. 记录执行时间
            result.execution_time_ms = int(
                (asyncio.get_event_loop().time() - start_time) * 1000
            )

            return result

        except asyncio.TimeoutError:
            return SkillResult(
                success=False,
                message=f"Skill {self.name} timeout after {self.config.timeout_seconds}s",
                skill_name=self.name
            )
        except Exception as e:
            return SkillResult(
                success=False,
                message=f"Skill {self.name} failed: {str(e)}",
                skill_name=self.name
            )

    @abstractmethod
    async def _do_execute(self, intent: Intent, context: HelixContext) -> SkillResult:
        """子类实现具体执行逻辑"""
        pass
```
