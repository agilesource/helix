## 📝 Implementation Notes

### Plugin Interface
```python
class Plugin(ABC):
    name: str
    version: str
    description: str

    def initialize(self, config: dict) -> None
    def execute(self, context: HelixContext) -> SkillResult
    def shutdown(self) -> None
```

### Adapter Pattern
Each AI engine adapter implements:
- `execute(prompt, context)` → response
- `tools()` → available tools
- `context_limit` → max tokens
