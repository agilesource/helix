## 六、发布流程

```bash
# 1. 更新版本号
vim src/helix/__init__.py

# 2. 运行测试
pytest tests/ --cov

# 3. 类型检查
mypy src/

# 4. 构建Docker
docker build -t helix:beta .

# 5. 创建Tag
git tag -a v1.0.0-beta.2 -m "Beta 2"

# 6. Push Tag
git push origin v1.0.0-beta.2

# 7. 创建Release (GitHub)
gh release create v1.0.0-beta.2 --title "Beta 2" --notes-file CHANGELOG.md
```

## 七、回滚策略

如果发现重大问题:

| 问题级别 | 处理 |
|---------|------|
| 阻断性bug | 回滚到上一版本 |
| 严重问题 | 修复后发新版RC |
| 轻微问题 | 记录，下一版本修复 |
