# Helix /verify 技能设计

> **版本**: v0.1
> **状态**: 详细设计

---

## 1. 技能概述

| 属性 | 值 |
|------|-----|
| 名称 | `/verify` |
| 分类 | Execution (执行引擎) |
| 依赖 | `/spec`, `/build` |
| 核心功能 | 自动化验证闭环 |

---

## 2. 工作流程

```
┌─────────────────────────────────────────────────────────────┐

│       │                                                     │
│       ▼                                                     │

│  │ 环境检测    │ ◄── 检测依赖、语言、框架                    │
│  └─────────────┘                                           │
│       │                                                     │
```

---

## 3. 验证层级

### 3.1 L1: 静态检查

| 检查项 | 工具 | 说明 |
|--------|------|------|
| 代码格式 | black, ruff | 格式规范 |
| 类型检查 | mypy | 类型安全 |
| Lint | ruff, flake8 | 代码质量 |
| 安全扫描 | bandit | 安全漏洞 |

### 3.2 L2: 单元测试

| 检查项 | 工具 | 说明 |
|--------|------|------|
| 测试运行 | pytest | 执行测试 |
| 覆盖率 | pytest-cov | 覆盖率检查 |
| 快速失败 | - | 任何测试失败则停止 |

### 3.3 L3: 验收测试

| 检查项 | 说明 |
|--------|------|
| Spec AC 验证 | 逐条验证验收标准 |
| 手动测试点 | 标记需要人工测试的点 |

---

## 4. CLI 接口

```bash
# 验证当前目录
helix verify

# 验证指定目录
helix verify ./src

# 仅静态检查
helix verify --level static

# 仅运行测试
helix verify --level test

# 完整验证
helix verify --level full

# 验收测试
helix verify --level acceptance

# 生成报告
helix verify --report json
```
